# Orientações do projeto

- O usuário pediu que as alterações sejam sempre atualizadas no site online: https://facilitador-financeiro-nsex.onrender.com/.
- Ao concluir alterações, execute os testes pertinentes, publique no serviço existente e verifique a versão online antes de informar que está pronta. Se houver um bloqueio de publicação, explique que a alteração ainda não está online.
- Preserve dados financeiros e credenciais. A demonstração pública deve usar somente dados fictícios isolados das contas reais.
